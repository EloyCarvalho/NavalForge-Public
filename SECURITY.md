# Security Policy

## Reporting

Do not disclose vulnerabilities, credentials, non-public source code, or private engineering data in a public issue.

Use GitHub's private vulnerability-reporting or security-advisory channel when available. Otherwise, contact the repository owner privately through the verified contact method shown on the owner's GitHub profile.

## Public repository boundary

This repository contains only public documentation and synthetic demonstration assets. Production systems, private datasets, and operational credentials are outside its scope.
