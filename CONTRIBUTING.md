# Contributing

This repository is maintained as a controlled public showcase.

Before opening an issue or pull request:

1. Read the [Public Data Policy](docs/PUBLIC_DATA_POLICY.md).
2. Use only synthetic examples and public information.
3. Do not attach native CAD, engineering evidence, customer material, logs, or environment files.
4. Run `./scripts/check_public_content.sh` locally.
5. Complete the disclosure checklist in the pull-request template.

If a report could reveal a security weakness or non-public information, do not open a public issue. Contact the repository owner through a private GitHub channel.
