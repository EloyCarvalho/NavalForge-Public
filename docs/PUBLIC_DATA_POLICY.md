# Public Data Policy

## Purpose

This repository is a public product and validation showcase. Every contribution must be safe for unrestricted internet access.

## Allowed content

- Synthetic or deliberately fictional vessel data
- Generic product descriptions
- Public interface visuals reviewed for disclosure risk
- High-level methodology without proprietary implementation details
- Public links and material already approved for release

## Prohibited content

- Customer, supplier, partner, or project identifiers
- Real hull geometry, native CAD, mesh, or production models
- Real weight reports, centers, loading conditions, or vessel particulars
- Commercial proposals, bids, contracts, prices, or procurement material
- Field trials, class correspondence, approval evidence, or internal reports
- Credentials, tokens, private keys, connection strings, or environment files
- Production source code or algorithms not explicitly approved for release

## Release gate

Before publication, every change must pass all of the following:

1. Automated path, content, and secret-pattern checks.
2. Manual review of images, PDFs, metadata, filenames, and embedded text.
3. Confirmation that all numerical data are synthetic or approved for release.
4. Owner approval before merging to the public default branch.

When classification is uncertain, the content remains private.
