# Asset Review Checklist

Use this checklist before publishing any image, PDF, video, CAD export, chart, or screenshot.

- [ ] Vessel and project names are fictional or approved for public use.
- [ ] Numerical data are synthetic or formally approved for release.
- [ ] No customer logos, drawing numbers, serial numbers, file paths, or account names appear.
- [ ] No browser tabs, notifications, email addresses, or private URLs are visible.
- [ ] Metadata and filenames contain no internal identifiers.
- [ ] Native engineering files and editable production models are excluded.
- [ ] The asset has received a final visual review at full resolution.
